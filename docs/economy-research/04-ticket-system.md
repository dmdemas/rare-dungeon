# 04 — Система Билетов

## Концепция

Билеты — механика удержания данжа. Чем дольше данж выживает, тем больше билетов получает владелец за каждую победу. В конце недели пул распределяется пропорционально билетам.

**Принцип**: вероятность выживания падает с каждым рейдом (Hard: 89% на рейд). Чем реже событие — тем выше награда. Минт-расписание построено пропорционально сложности выживания.

## Wipe и transfer

- Если Friend клирит данж: **90% ticket power данжа → рейдеру**, 10% сжигается
- Если владелец снимает банк: билеты остаются до конца недели

## Код

```typescript
// economy.ts
TICKET_MINT_SCHEDULE: { 7:1, 8:2, 9:2, 10:3, ... 25:64 }
ticketMintAtWin(wins: number): number
TICKET_POOL_FRAC = 0.25
PROTOCOL_WEEKLY_BURN_FRAC = 0.005

// App.tsx
onOutcome('dead'): ticketMintAtWin(wins) → bp.ticketPower
onOutcome('won'): 90% of bp.ticketPower → raiderTicketPower
onClaim: ticketPower stays until week-end
onSettleWeek: distribute wallet.rewardPool × frac proportionally
```

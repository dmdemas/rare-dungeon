## Спецификация (1 страница)

### Пулы (не смешивать)
**Friend (6):** Fearless, Dash, Sharp Eye, Endurance, Rally, Dodge  
**Dungeon (6):** Dreadful Beasts, Sharp Claws, Fog, Thick Hide, Walls, Horde  

Ролл оффера: **равный 1/6**, всегда **2 разных** (дубль → реролл второй). UI-текст только EN. Картинка только из своей папки по имени перка; нет файла — не подставлять соседний.

### База Friend
Vision 5, Stamina 20, Attack 1 (жизнь = стамина).  
Зрение: `max(1, 5 + SharpEye − Fog)`.  
Испуг: `clamp(25 + DreadfulBeasts + FogFright − Fearless − SharpEyeFright, 0, 95)`.

### Ранги
Линия I→II→III; действует только текущий ранг. Повтор той же линии апгрейдит стейт по id. Линия уже III — в оффер не попадает. Слоты хранят историю иконок; ранг — отдельно.

### Friend — эффекты
| Perk | Type | I / II / III |
|------|------|----------------|
| Fearless | Defense | −25% / −50% / −75% к шансу flinch (не ниже 0% вклада перка в формулу выше) |
| Dash | Mobility | 2 / 3 / 4 шага к выходу без стамины после урона; не в стену/моба; 1× за удар |
| Sharp Eye | Vision | +1 / +2 / +3 зрения; −5% / −10% / −15% к шансу flinch |
| Endurance | Stamina | +2 / +3 / +4 max stamina (только текущий ранг) |
| Rally | Recovery | +2 / +2 max 2× за этаж / +2 без лимита этажа; ≤ max stamina |
| Dodge | Defense | 25% / 50% / 75% ignore hit; без free step / skip tick |

### Dungeon — эффекты
| Perk | Type | I / II / III |
|------|------|----------------|
| Dreadful Beasts | Control | +25% / +50% / +75% к испугу (cap 95% итог) |
| Sharp Claws | Offense | +1 / +2 / +3 урон мобов к базе |
| Fog | Vision | −1 / −2 / −3 зрения (пол ≥ 1); +5% / +10% / +15% к испугу |
| Thick Hide | Defense | +1 / +2 / +3 HP мобов к базе |
| Walls | Map | 2–4 / 4–6 / 6–8 стен (uniform); путь обязателен |
| Horde | Spawn | +1 / +2 / +3 мобов на свободный пол |

**Walls/Horde:** не entrance/exit; сначала lock пути к выходу, затем спавн только в безопасные клетки; нет клетки — skip.

### Play
1. До хода этапа: fade in **Friend** — 2 карточки → клик → иконка в левый слот 1/2/3.  
2. Перки данжа **уже заданы** создателем (для теста — рандомный loadout при старте рейда). После выбора Friend **раскрывается** следующий правый слот данжа + stub apply. Игрок данж **не выбирает**.  
3. Можно ходить. ×3 раунда (слоты слева Friend / справа Dungeon).

### Create Dungeon
После выбора макета: 3 раунда выбора из пула Dungeon (`DungeonPerkSelection` / `DungeonPerkSlot`).  
ROUND 1→2→3 после каждого выбора. Превью карты обновляется сразу, эффекты **накапливаются**. После 3 слотов — **Enter** создаёт карту.

### Предопределённые данжи
Генерируются / кладутся в пул уже с **3 случайными** перками данжа (тот же пул, равный шанс, правила апгрейда/уникальности оффера как выше).

### Тултип (hover)
Формат: Name / Type / one short rule / I·II·III.  
Чужой пул не показывать. Рядом с карточкой, не перекрывая клик. Уже взятая линия: подсветка текущего + следующего ранга. На III карточку не предлагать.

# 02 — Soft Экономика

## Параметры

| Параметр | Значение |
|----------|---------|
| Create | $2 ($1.5 банк + $0.5 fee) |
| Entry | $1 ($0.9 банк + $0.1 pool) |
| Clear rate | ~33% |
| minWinsBeforeClaim | 0 |
| Suggested close | 1.5× |
| Friend clear раздел | 95% рейдеру / 5% pool |

## Результаты (из симуляций)

| Метрика | Факт | Цель |
|---------|------|------|
| Clear rate/рейд | 33% | 30–36% ✅ |
| Рейдер × при клире | 2.93× | 2–5× ✅ |
| Владелец ROI (avg) | **0.60×** | 1–2× ❌ |

## Почему Owner ROI < 1× — и это нормально

**Математическое объяснение:**
- P(зачищен на 1-м рейде) = 33% → владелец получает $0
- P(зачищен на 2-м рейде) = 22% → владелец получает $0 (или $3.14 если успел закрыть)
- До win 2 (suggested close) доживают только ~45% данжей

**Conditional ROI** (тем, кто дожил до win 2) = 1.57×. Это правильно.

**Averaged ROI** = 0.60× из-за высокого clear rate.

**Вывод:** Soft — это гэмбл для создателей. Высокий риск (33% clear rate) оправдан малой ценой ($2). Это дизайн-решение, не баг. Лечится только снижением clear rate ниже 20% — но тогда Soft перестаёт быть лёгким для рейдеров.

## Что работает в Soft

- Рейдеры получают **2.93×** при клире — честный возврат
- Pool из Soft fees подпитывает общий rewardPool
- Без реролла-перков → простая механика создания

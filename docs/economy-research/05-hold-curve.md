# 05 — Hold Curve (Исследование удержания данжа)

## Задача

Заменить жёсткий блок `minWinsBeforeClaim = 7` на экономический стимул без hard lock.

## Исследованные варианты (sim-hard-hold-curve.ts)

|---------|-------------|------|-----------|---------|
| V0: lock 7, без билетов | 7.3 | 0% | 1.44× | $0 |
| V6: lock 7 + smooth mint | 7.65 | 1.2% | 2.42× | $3.23 |

| **V10: near-lock + survival mint** | 6.53 | 0.0% | 1.24× | $1.69 |

## Финальный выбор: Near-lock 95→0% + survival-mint

**Налог (near-lock)**: 95/90/80/70/50/20/5/0% для побед 1–8+

**Причина выбора**: Технически можно снять в любой момент. Экономически убыточно до win 6 (налог убивает прибыль). Win 7 = unlock zone (5% налог, $110 = 3.67×).

**Ключевое открытие**: 
- Средний холд без билетного стимула = 5.9–6.5 (слабовато)
- С near-lock tax средний холд = 8.4 (из финального сима)
- Нет ни одного варианта, который даёт И win 7 = 3×, И owner avg = 2×, И ≥15× для 2-3% — математическое противоречие

## Почему owner avg 2× недостижимо

```
Требуется: ticket_bonus / ownerSpend ≥ 0.69×  (чтобы 1.31 + 0.69 = 2×)
Вычисляем: ownerSpend = 200 × $30 = $6000/нед
Нужно: $4140 в год → ticket payouts к владельцам
Имеем: pool × 0.25 × 0.40 = $5700 × 0.25 × 0.40 = $570/нед
$570 ≠ $4140 → недостижимо
```

60% данжей зачищают до win 7, их владельцы получают $0 и 0 билетов. Это фундаментальное ограничение при clear rate 11%.
